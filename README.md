# Booked_online_food
Le book_online_food est un outil construit envie de valoriser la culture ngala à  travers ses recettes.
l'outil tient à présenter les différents plats que peux régorger cette culture à travers des illustrations qui permettent de voir comment est-ce que l cuisson est faites

# Functionalités 
-   la possibilité de réserver un plat en ligne
-   la possibilité de donner ses arguments sur un plat
-   la possibilité de concter le service Booked_online_food
-   une partie administration où l'on gère les différentes réservations
-   un panel utilisateur
-   un panel cuisson qui réprésente la cuisson de chaque plat inscris dans le menu

# Conseils
